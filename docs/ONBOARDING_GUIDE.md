# Guide Onboarding - BunnyManager

## Pourquoi ces informations sont demandées ?

Lors de votre première utilisation de BunnyManager, l'application vous pose quelques questions simples. Voici pourquoi :

### 🐰 Type d'élevage
**Pourquoi ?** Pour adapter les fonctionnalités à vos besoins réels.
- Un élevage familial n'a pas les mêmes besoins qu'un élevage professionnel
- Cela nous permet de vous proposer des conseils adaptés

### 🏠 Informations sur votre ferme
**Pourquoi ?** Pour mieux comprendre votre contexte.
- Le nom de la ferme (optionnel) personnalise votre expérience
- La région/pays nous aide à adapter les recommandations (climat, pratiques locales)
- La taille de l'élevage nous aide à optimiser l'interface

**Important :** Aucune adresse précise n'est demandée. Ces informations restent sur votre appareil.

### 👤 Votre profil
**Pourquoi ?** Pour personnaliser les conseils.
- Un débutant aura plus d'explications qu'un expert
- Un vétérinaire n'a pas les mêmes besoins qu'un propriétaire

---

## Ce qui est synchronisé (si autorisé)

Si vous acceptez la synchronisation, seules ces données **anonymes** sont envoyées pour améliorer l'application :

✅ **Synchronisé (anonymement) :**
- Statistiques générales (nombre de lapins, portées moyennes)
- Tendances de reproduction et de santé (agrégées)
- Données techniques pour corriger les bugs

---

## Ce qui n'est JAMAIS synchronisé

🔒 **Jamais envoyé, jamais partagé :**
- Votre nom, email, ou coordonnées personnelles
- Les noms de vos lapins
- Vos photos
- Votre localisation précise
- Vos données financières détaillées

---

## Modifier vos choix plus tard

Vous pouvez toujours modifier ces paramètres dans :
**Paramètres** → **Confidentialité et synchronisation**

---

## Questions fréquentes

### Puis-je utiliser l'application sans Internet ?
**Oui !** BunnyManager est conçu pour fonctionner 100% hors-ligne. Toutes vos données sont stockées sur votre appareil.

### Mes données sont-elles en sécurité ?
**Oui !** Vos données sensibles restent sur votre appareil. Seules les données anonymes sont synchronisées, et uniquement si vous l'autorisez.

### Puis-je changer d'avis sur la synchronisation ?
**Oui !** À tout moment dans les paramètres de l'application.
